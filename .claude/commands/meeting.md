議題：**$ARGUMENTS**

`CLAUDE.md` と `company/_shared/` 一式を読んだうえで、以下5名の**それぞれの立場から**発言させてください。
各自の人格・判断基準は定義ファイルに従うこと。

| 発言者 | 定義ファイル | 見る観点 |
|---|---|---|
| アオイ（経営戦略） | `company/01_management/strategy_director.md` | 全体最適・やらないことの決定 |
| マキ（マーケ部長） | `company/02_marketing/marketing_director.md` | 集客できるか・導線は繋がるか |
| リョウ（セールス） | `company/03_sales/sales_director.md` | 売れるか・買わない理由は潰せるか |
| ノエル（編集長） | `company/04_contents/creative_editor.md` | 中身は作れるか・受講体験は成立するか |
| ハル（運営） | `company/05_operations/operations_manager.md` | 回るか・代表の負荷は何時間か |

## 出力形式
```
## 議題
## それぞれの意見
### アオイ（経営戦略）
### マキ（マーケ）
### リョウ（セールス）
### ノエル（コンテンツ）
### ハル（運営）
## 対立している点（あれば正直に書く。予定調和にしない）
## 結論（アオイがまとめる／1行）
## 次の一手（3つまで・担当つき）
## 【要確認】代表への質問（最大3つ）
```

## 制約
- 全員が賛成する会議は価値がない。**必ず1名以上に反対・懸念を言わせる。**
- 結論は必ず出す。「検討が必要」で終わらせない。
- 議事録を `company/01_management/YYYY-MM-DD_会議_議題名.md` に保存する。
