# 髙落まどか｜バーチャルカンパニー

食と生活リズムをテーマにした講座・発信のためのリポジトリ。
**Claude Code で開くと、5人のAIスタッフが立ち上がります。**

## まず読む

| ファイル | 内容 |
|---|---|
| **`company/HOW_TO_RUN.md`** | **動かし方。週30分でまわす設計** |
| `CLAUDE.md` | 企業理念・ターゲット・トーン＆マナー・全スタッフの行動原則 |
| `company/README.md` | 組織図と各部署の役割 |

## すぐ使えるコマンド

| コマンド | 内容 | 代表の時間 |
|---|---|---|
| `/kickoff` | 今週やること3つを決める（月曜） | 5分 |
| `/weekly` | KPI更新と振り返り（金曜） | 5分 |
| `/braindump` | 思いつきを投げると分解してタスク化 | 随時 |
| `/sns` | 投稿・リールの構成と素材をつくる | — |
| `/lp` | LP・セールス原稿を書き切る | — |
| `/meeting` | 5人の視点で議題を検討する | 10分 |
| `/status` | 会社の現在地を30秒で確認 | 30秒 |

**メモを渡すだけでも動きます。**

```
メモ：夏休み明け、朝ごはんが食べられない子が多い。
      まず起床時間を揃えるところからでは。
```

内容に合った形式（リール台本・メルマガなど）を選び、原稿にしてフォルダへ保存します。
分類ルールは `.claude/skills/draft/SKILL.md`。

## フォルダ

| フォルダ | 中身 |
|---|---|
| `company/` | バーチャルカンパニー（経営・マーケ・セールス・コンテンツ・運営） |
| `original/` | 受け取ったメモの原文。整形せずそのまま残る |
| `ideas/` `reels/` `stories/` `newsletter/` `captions/` | 形式別の原稿 |
| `meishi/` | 名刺データ |
| `build_deck.js` | 講座スライド生成（`node build_deck.js` で .pptx を出力） |

## 講座スライドをビルドする

```bash
npm install
node build_deck.js
```
