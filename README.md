# madoka-content-system

食と生活リズムをテーマにした講座と SNS 発信のためのリポジトリ。
思いついたメモを、そのまま使える原稿にして溜めていく。

## 使い方

このリポジトリで Claude Code を開き、メモを渡すだけ。

```
メモ：夏休み明け、朝ごはんが食べられない子が多い。
      まず起床時間を揃えるところからでは。
```

内容に合った形式（リール台本・メルマガなど）を選び、原稿にしてフォルダへ保存します。
形式を決めたいときはそう言えば従います。

```
さっきの話、メルマガでお願い
このメモからリールとキャプションを両方作って
```

サーバーや API キーの設定は要りません。分類ルールは `.claude/skills/draft/SKILL.md`
に書いてあるので、書き方の好みが変わったらこのファイルを直してください。

## フォルダ

| フォルダ | 中身 |
| --- | --- |
| `original/` | 受け取ったメモの原文。整形せずそのまま残る |
| `ideas/` | まだ形になっていない着想・企画の種 |
| `reels/` | 30〜60秒のショート動画台本（フック／本編／締め） |
| `stories/` | ストーリーズ用の短文（3〜5枚構成） |
| `newsletter/` | メルマガ本文（件名＋600〜1200字） |
| `captions/` | フィード投稿のキャプション（＋ハッシュタグ） |

原稿には YAML フロントマター（`title` / `category` / `tags` / `summary` /
`source_note` / `status`）が付くので、後から検索・整理できます。

## 講座スライド

```bash
npm install
npm run build:deck
```

`build_deck.js` から `夏休みの終わり_第2回_食と生活リズムの整え方.pptx` を生成します。

## 原稿の扱いについて

メモに書かれていない栄養情報・数値・研究結果・エピソードは生成しません。
裏付けが要ると判断した箇所は、原稿中に `[要確認]` と入ります。そこだけ確認してください。
