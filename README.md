# 現在地ノート

**まず、何も変えずに観察。**

ダイエットを「頑張る」前に、自分の現在地を知るための記録アプリです。
ブラウザで `index.html` を開くだけで動きます。インストール不要・通信なし。

---

## なぜ「何も変えない」ところから始めるのか

うまくいかないダイエットは、たいてい **自分の現在地を知らないまま、他人の正解を当てはめる** ところから始まります。

- 何時に食べているか
- どんな日に甘いものが欲しくなるか
- 体重が増える前日に何が起きているか

これを知らずに「糖質を減らす」「運動する」を始めても、
効いたのか効かなかったのかが分かりません。だから続きません。

このアプリは3つのフェーズをぐるぐる回します。

| | フェーズ | やること |
|---|---|---|
| 1 | **観察（14日）** | 何も変えない。いつも通りに過ごして、そのまま記録する |
| 2 | **発見** | 記録どうしの関係をアプリが自動で探し、あなたのパターンを出す |
| 3 | **一手** | 変えるのは **1つだけ**。2週間続けて、また観察に戻る |

同時に2つ以上変えると、何が効いたのか永久に分かりません。
**1回に1つ**が、遠回りに見えていちばん確実です。

---

## 記録する12項目

| 項目 | 入力 | なぜ見るのか |
|---|---|---|
| 体重・体脂肪 | 数値 | 日々の上下は水分。7日平均の向きだけを見る |
| ウエスト | 数値 | 体重が動かなくても、先に減ることがある |
| 写真 | 撮影・選択 | 数字より正直。同じ場所・同じ服・同じ姿勢で |
| 食事 | 朝昼夕の時刻とメモ | 量ではなく「いつ・何を」。夕食の時刻が効くことが多い |
| 間食 | 回数＋メモ | 本人が思っているより多い。数えるだけで変わる |
| 睡眠 | 就寝・起床・眠りの質 | 寝不足は翌日の食欲を確実に押し上げる |
| 運動 | 分数＋内容 | 消費カロリーより、睡眠と疲れへの効き目を見る |
| 疲れ | 5段階 | 疲れは甘いもの欲求の引き金になりやすい |
| お通じ | あり／なし＋状態 | むくみ・体重の見かけ上の増減に直結する |
| むくみ | 5段階 | 「増えた」の正体がむくみだと分かれば落ち込まない |
| 甘いもの欲求 | 5段階 | 意志の強さではなく、条件で決まっていることが多い |
| 空腹感 | 5段階 | 食事内容が足りているかのいちばん正直なサイン |

空欄があっても大丈夫です。**途切れても翌日また書く**のが、唯一の続けるコツです。

## アプリが自動で探す「あなたのパターン」

記録がたまると、項目どうしの関係を勝手に探して日本語で出します。たとえば：

> **寝不足の日は、空腹感が強くなりやすい**
> 睡眠 7.4時間の日：空腹感 2.1 ／ 5.6時間の日：3.8
> この比較に使った日数：12日

翌日にずれて効くもの（間食 → 翌朝の体重、夕食の時刻 → 翌日のむくみ、
運動 → その夜の眠りの質）も、日付をずらして照合します。
曜日のクセ（「金曜だけ間食が増える」など）も見つけます。

観察期間が終わると、いちばん強く出たパターンから
**「次の一手」を1つだけ** 提案します。

> 統計的な証明ではなく「あなたの記録の中での傾向」です。日数が増えるほど信頼できます。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. スマホで使う場合：
   - iPhone → Safariで開く → 共有ボタン → **ホーム画面に追加**
   - Android → Chromeで開く → メニュー → **ホーム画面に追加**
   アプリのように起動できるようになります
3. 「きょう」の画面で、分かるところだけ入力（自動保存）
4. 14日たったら「ふりかえり」を見る

### 画面

- **きょう** … その日の記録。日付は ‹ › で移動でき、後から書き足せます
- **ふりかえり** … 体重・ウエストのグラフ、からだの声のヒートマップ、あなたのパターン、次の一手
- **写真** … 全部の写真と、2枚を並べての見比べ
- **きろく** … 観察のルール、設定、記録一覧、バックアップ

---

## データについて

- データは **その端末のブラウザの中だけ** に保存されます（localStorage）
- どこにも送信されません。アカウントもサーバーもありません
- ブラウザのデータを消すと記録も消えます。
  **「きろく」画面から、ときどき書き出してください**（JSONファイル）
- 保存できる容量はおおよそ5MBです。写真は自動で縮小されますが、
  写真を毎日撮る場合は数か月分でいっぱいになります。書き出して整理してください

---

## 技術メモ

- 単一HTMLファイル。ビルド不要、依存ライブラリなし、外部通信なし
- グラフは手書きのSVG、体重は7日移動平均を主線として描画
- パターン検出は中央値で2群に分け、各群3日分以上・効果量が閾値以上のものだけ提示
- ライト／ダークの両方に対応（右上のボタンで切替）

## 注意

体重計の数字は健康のごく一部です。
体調に不安があるとき、持病があるとき、極端な数字が出たときは医療者に相談してください。
このアプリは診断や治療のためのものではありません。
