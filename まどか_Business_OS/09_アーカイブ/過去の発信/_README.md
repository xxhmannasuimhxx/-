# 過去の発信

## 入れるもの

- やめた媒体の過去記事
- 内容が古くなった発信（基準改定などで事実が変わったもの）
- 1年以上前の投稿で、`05_発信/` が重くなってきたもの

## ★ 先に確認すること

移す前に「これは定番にできないか」を考えてください。
反応が良かったものは、アーカイブではなく
`04_コンテンツ資産/03_定番コンテンツ/` に昇格させるべきものです。

**アーカイブは「もう使わないもの」の置き場**です。
良かった発信をここに入れてしまうと、資産が埋まってしまいます。

## 内容が古くなったものの扱い

事実が変わったものは、消さずに移して、冒頭にこう書いておく。

```
※ この内容は YYYY年時点の基準に基づいています。
   最新の内容は 04_コンテンツ資産/05_栄養の知識ベース/◯◯.md を参照。
```

こうしておくと、うっかり古い情報を使ってしまう事故を防げます。
