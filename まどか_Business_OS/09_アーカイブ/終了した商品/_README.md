# 終了した商品

## 入れるもの

販売をやめた商品のフォルダを、`02_商品/` からそのまま移してくる。

## 移す前にやること

商品フォルダの中に `終了メモ.md` を作って、次の3つを書いてください。

```markdown
# 終了メモ

## 販売期間
## 提供した人数
## なぜ止めたか
（需要がなかった / 自分が続けられなかった / 時期が合わなかった）
## 良かったところ（次に使える部分）
## お客様の反応
```

そして `../アーカイブ台帳.md` に1行追記する。

## ★ 使える部分は残す

商品ごと止めても、中の一部（ワークシート、説明の順番、特典）は使えます。
「良かったところ」に書いておけば、次の商品を作るときに拾えます。
