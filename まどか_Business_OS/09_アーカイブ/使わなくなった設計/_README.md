# 使わなくなった設計

## 入れるもの

- 途中でやめた企画・キャンペーン
- 作ったけど使わなかったセールス導線
- 試して合わなかった運用のしくみ
- 書いたけど公開しなかった原稿

## ★ ここは宝の山になります

「やろうとしてやめたこと」には、そのときの自分の判断が入っています。
時期が合わなかっただけのものが、かなりあります。

移すときは `../アーカイブ台帳.md` に、
やめた理由を3分類（需要／自分の都合／時期）のどれかで書いてください。
**「自分の都合」「時期」でやめたものは、復活の第一候補**です。

## 四半期の見直しのときに

このフォルダをざっと眺めて、
「今ならできるかも」と思うものがあれば元の場所に戻してください。
戻したら `../アーカイブ台帳.md` の「復活させたもの」に記録します。
