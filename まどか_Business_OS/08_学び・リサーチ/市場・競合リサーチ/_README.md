# 市場・競合リサーチ

## 入れるもの

同じ領域で発信している人・サービスの観察記録。

## ★ 何のために見るか

**真似するためではありません。** 見るのは次の2つだけ。

1. **誰も言っていないこと**（＝自分が言うべきこと）
2. **お客様が他で満たされていない部分**（＝自分の商品の余白）

比べて落ち込むために見るのは時間の無駄です。
上の2つが1つも見つからなかったら、その日のリサーチは終わりにしてください。

## ファイルに書くこと

```markdown
# YYYY-MM リサーチ：テーマ

## 見た対象（3〜5）
| 名前 | 誰に向けているか | 何を売っているか | 価格帯 | 強み |

## 多くの人が言っていること

## ★ 誰も言っていないこと

## ★ お客様が満たされていなさそうな部分

## 私がやるべきこと（1つ）
```

## 命名例

- `2026-09_リサーチ_40代向け食事指導サービス.md`

## 頻度

四半期に1回で十分です。頻繁に見ると発信がぶれます。
