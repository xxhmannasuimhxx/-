# 専門情報アップデート

## 入れるもの

管理栄養士として押さえておくべき、**基準や指針の変更**。

- 日本人の食事摂取基準の改定
- 各学会の診療ガイドライン改訂
- 食品表示・特定保健用食品などの制度変更
- 広告表現に関わる法令の運用変更（薬機法・景品表示法など）

## ★ 必ず書くこと

```markdown
# YYYY-MM 改定名

## 出典
（正式名称・発行元・年）

## 何が変わったか

## ★ 自分の発信・資料のどこを直す必要があるか
- 04_コンテンツ資産/05_栄養の知識ベース/◯◯.md の数値
- 04_コンテンツ資産/03_定番コンテンツ/◯◯.md
- 既存スライド（04_コンテンツ資産/06_既存資料の索引.md 参照）

## 直した？
- [ ] 直した（日付：）
```

**「どこを直す必要があるか」が本題**です。
基準が変わったのに古い資料を使い続けるのが、一番避けたいことです。

## 命名例

- `2026-09_食事摂取基準改定メモ.md`

## 頻度

年1〜2回、まとめて確認する時間を取るのがおすすめです。
