# 学びログ

## 入れるもの

本・講座・セミナー・記事から学んだことの一次メモ。
テンプレート：`../_テンプレート/学びログ.md`

## 命名例

- `2026-09-14_学び_書名.md`

## ★ 埋めるのは3つだけでいい

1. 一番刺さった1つ
2. 私のビジネスにどう使うか
3. 次の1週間でやること

丁寧に要約しても使いません。この3つだけ書いてください。

## 資産化の確認（月1回）

このフォルダを開いて、**「資産化した？」がすべて未チェックのファイル**を探してください。
それは「学んだけど何も変わらなかった」学びです。

- 使えるなら → 今すぐ `04_コンテンツ資産/` か `06_セールス/` に反映する
- 使えないなら → `09_アーカイブ/` へ移す

ここが溜まりすぎると「学んでいるのに進まない」感覚の原因になります。
