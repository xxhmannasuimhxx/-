# 08_学び・リサーチ

## このフォルダの役割

外から入れた知識の置き場。ただし**ここに置いたままでは資産になりません。**

```
本・講座・セミナーで学ぶ
   ↓
08_学び・リサーチ/学びログ/ に書く（一次メモ）
   ↓ 自分の言葉になったら
04_コンテンツ資産/ へ移す（＝資産化）
```

★ **この移動が起きない学びは、忘れます。**
だから `_テンプレート/学びログ.md` には
「私のビジネスにどう使うか」という欄を必須にしてあります。

## 入れるもの

- 本・講座・セミナーの学び（`学びログ/`）
- マーケティングの原則（`マーケティング原則集.md`）
- 市場・同業者のリサーチ（`市場・競合リサーチ/`）
- ガイドライン改訂などの専門情報（`専門情報アップデート/`）

## 入れないもの

- 自分の体験・気づき → `04_コンテンツ資産/02_気づき・体験ログ/`
- 自分の言葉になった知識 → `04_コンテンツ資産/05_栄養の知識ベース/`

## 命名例

- `学びログ/2026-09-14_学び_書名またはセミナー名.md`
- `市場・競合リサーチ/2026-09_リサーチ_40代向け食事指導サービス.md`
- `専門情報アップデート/2026-09_食事摂取基準改定メモ.md`
