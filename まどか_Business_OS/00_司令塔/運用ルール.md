# 運用ルール

このOSを半年後も使える状態に保つためのルール。**迷ったらここに戻る。**

---

## 1. ファイル名のつけ方

```
YYYY-MM-DD_種類_タイトル.md
```

例：
- `2026-09-14_気づき_夏休み明けに食欲が戻らない人の共通点.md`
- `2026-09-01_お客様の声_C003_3ヶ月で朝が楽になった.md`
- `2026-09-10_メルマガ_タンパク質は朝が勝負.md`

**なぜこの形か**
- 日付が先頭 → 自動的に時系列に並ぶ
- 種類が入る → 一覧を見ただけで中身が分かる
- タイトルが具体的 → 検索で引っかかる

**種類に使う言葉（これ以外は増やさない）**
`気づき` / `お客様の声` / `カルテ` / `投稿` / `メルマガ` / `セミナー` / `学び` / `リサーチ` / `商品設計` / `ローンチ` / `振り返り`

**日付が要らないもの**（ずっと更新し続けるファイル）は日付なしでいい。
例：`ブランドコア.md` `商品一覧.md` `04_たとえ話・フレーズ集.md`

---

## 2. タグのつけ方

**すべてのファイルの冒頭**に、この5行を置く。空欄があってもいい。

```
対象:
悩み:
商品:
媒体:
状態:
```

こうしておくと「40代・便秘」の素材だけを横断で取り出せます。

### タグ辞典（★ここに無い言葉は使わない。増やすときはここに追記してから）

**対象**（誰に向けたものか）
`40代女性` `50代女性` `60代以上` `子育て中` `働く女性` `更年期` `ダイエット中` `健診で指摘された人` `家族の食事を作る人`

**悩み**（何に困っているか）
`便秘` `疲れやすい` `眠れない` `体重が落ちない` `血糖値` `コレステロール` `貧血` `食欲がない` `食べすぎる` `続かない` `何を食べたらいいか分からない` `料理が面倒`

**商品**
`02_商品/商品一覧.md` にある商品名をそのまま書く。

**媒体**
`Instagram` `メルマガ` `ブログ` `note` `LINE` `セミナー` `講座` `個別相談`

**状態**
`素材`（まだ使っていない）/ `下書き` / `公開済み` / `定番`（何度も使う）/ `保留` / `廃止`

---

## 3. 索引ファイルのルール

各フォルダの `_README.md` には必ずこの4つを書く。

1. このフォルダの役割
2. 入れるもの
3. 入れないもの（← これが一番効く）
4. 命名例

新しいサブフォルダを作ったら、親の `_README.md` に1行追記する。

---

## 4. 運用リズム

| いつ | やること | 時間 |
|---|---|---|
| 毎日 | 気づきを `_INBOX.md` に1行 | 1分 |
| **週1回** | **INBOXの棚入れ。素材を04へ、悩みを03へ** | **15分** |
| 月1回 | `07_数字/月別データ/` に記入 → 刺さった投稿を1行メモ | 20分 |
| 四半期 | 01と02を見直す。使わないものは09へ | 60分 |

**必須は週1回の15分だけ。** ここだけ守れば、崩れても復旧できます。
1ヶ月空いても気にしないでください。INBOXから再開できるように作ってあります。

---

## 5. 個人情報を書かない

このOSはGitで管理されているため、**一度書いたものは履歴に残り、削除しても履歴からは消えません。**

書かないもの：
- お客様の本名・メールアドレス・電話番号・住所・SNSアカウント名
- 健診結果などの医療情報で、本人が特定できる形のもの
- 決済情報、パスワード、APIキー

書き方：
- お客様は `C001` のようなIDと、必要なら**イニシャルだけ**で管理する
- 本名とIDの対応表は、このOSの**外**（顧客管理ツールや手元の非公開ファイル）に置く
- お客様の声は**掲載許可を得たものだけ**を入れ、ファイル内に `許可: 済（YYYY-MM-DD）` を書く

詳しくは `03_顧客/_README.md`。

---

## 6. アーカイブのルール（捨てない）

やめた商品・古い発信は**消さずに** `09_アーカイブ/` へ移す。
移すときは `09_アーカイブ/アーカイブ台帳.md` に **「なぜ止めたか」** を1行書く。

理由が残っていれば、数年後に「あれもう一度やろう」と思ったときに再利用できます。
理由のない資料は再利用できません。

---

## 7. AIと一緒に使う

Markdown（`.md`）で書いてあるので、フォルダごと渡して指示できます。

- 「`03_顧客/お客様の声/` から、40代向けメルマガの冒頭を3案」
- 「`04_コンテンツ資産/` を見て、Instagram投稿を5本」
- 「`07_数字/` を見て、先月伸びた投稿の共通点を分析して」
- 「この文章が `01_ブランド/ブランドコア.md` と合っているかチェックして」

**そのために大事なこと**：写真やPDFではなく、**文字で書き残す**こと。
写真しかない資料は、ファイル名と `_README.md` に「何が写っているか」を文字で書いておく。
