# 00_司令塔

## このフォルダの役割

「いま何をやるか」を決める場所。**このOSの入口**です。
毎日開くのはここだけで済むようにしてあります。

## 入れるもの

- 思いついたこと・気づいたこと（→ `_INBOX.md`）
- 今月・今期の目標と進行中のこと（→ `ダッシュボード.md`）
- 年間・四半期の計画（→ `年間計画/`）

## 入れないもの

- 完成した原稿 → `05_発信/`
- お客様の情報 → `03_顧客/`
- 発信のネタ → `04_コンテンツ資産/01_ネタ帳.md`

司令塔は「短く・少なく」保つのがコツです。増えてきたら各フォルダへ棚入れします。

## 命名例

- `年間計画/2026_年間計画.md`
- `年間計画/2026Q4_四半期計画.md`
