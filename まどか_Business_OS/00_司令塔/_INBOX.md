# INBOX（とりあえず放り込む場所）

## 使い方

**迷ったら分類せず、ここに1行書く。** それだけです。
分類は週1回まとめてやります（下の「棚入れのしかた」参照）。

- 日付を付けて、1行でいい
- 誤字も言葉足らずも気にしない（あとで自分が思い出せればいい）
- 書きながら「これは発信に使えそう」と思ったら末尾に `→発信` と付けておく

## 棚入れのしかた（週1回・15分）

上から順に見て、行き先を決めて移動する。

| 内容 | 行き先 |
|---|---|
| 発信に使えそうな気づき・体験 | `04_コンテンツ資産/02_気づき・体験ログ/` |
| 発信のアイデア | `04_コンテンツ資産/01_ネタ帳.md` |
| お客様の言葉・悩み | `03_顧客/よくある悩み・質問.md` |
| 商品のアイデア | `02_商品/商品アイデア.md` |
| 学んだこと | `08_学び・リサーチ/学びログ/` |
| うまい言い回し・たとえ話 | `04_コンテンツ資産/04_たとえ話・フレーズ集.md` |
| やること | `00_司令塔/ダッシュボード.md` |
| どこにも行かない | 消す（消すのも仕事です） |
