# 02_気づき・体験ログ

## 入れるもの

日々の気づき・自分の体験・仕事中に感じたこと。
**「発信になるか」を考えずに書く**のがコツです。あとで見返すと使えるものが混ざっています。

1ファイル1気づきでも、1週間まとめてでも構いません。続けやすい方で。

## 命名例

- `2026-09-14_気づき_朝食を抜く人の本当の理由.md`
- `2026-09_気づきまとめ.md`（月まとめ型にする場合）

## 書く内容

テンプレート：`../_テンプレート/気づきログ.md`

## 入れないもの

- 外から学んだこと → `08_学び・リサーチ/学びログ/`
- お客様の発言そのもの → `03_顧客/よくある悩み・質問.md`

（ただし厳密に分けなくていいです。迷ったらここに書いてください。）
