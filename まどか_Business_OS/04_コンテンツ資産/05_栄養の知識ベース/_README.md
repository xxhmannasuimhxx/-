# 05_栄養の知識ベース

## 入れるもの

テーマ別に整理した知識。**発信の裏付け**と、**説明を毎回考え直さないため**の場所です。

## テーマの例（必要になったら作る。最初から全部作らない）

- `腸と便通.md`
- `たんぱく質.md`
- `血糖値.md`
- `鉄・貧血.md`
- `更年期と食事.md`
- `睡眠と食事.md`
- `高齢者の低栄養.md`

## ファイルの中に書くこと

```
# テーマ名

タグ5行

## 一言でいうと
## お客様に説明するときの言い方   ← ★ここが一番価値がある
## 押さえておく数値・基準
## よくある勘違い
## 出典（ガイドライン名・年）
## 関連する発信（05_発信のどれか）
```

## ★「お客様に説明するときの言い方」を必ず書く

正しい知識は調べればあります。このOSに書く価値があるのは
**24年かけて見つけた「伝わる説明」**の部分です。

## 出典を書く理由

栄養の基準は改訂されます。出典と年が書いてあれば、
改訂時にどこを直すべきか分かります。
→ 改訂情報は `08_学び・リサーチ/専門情報アップデート/` に記録

## 入れないもの

- 発信の原稿 → `03_定番コンテンツ/` または `05_発信/`
- 学んだことの一次メモ → `08_学び・リサーチ/学びログ/`
