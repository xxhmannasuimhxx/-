# 04_コンテンツ資産 ★このOSの心臓部

## このフォルダの役割

**発信の材料庫。** 「何を書こう」と悩む時間をなくすための場所です。
ここに素材が溜まっていれば、発信は「作る」ではなく「組み立てる」になります。

## 中身の役割分担

| フォルダ・ファイル | 何を入れるか |
|---|---|
| `01_ネタ帳.md` | 「これ発信できそう」の一覧。状態を管理する |
| `02_気づき・体験ログ/` | 日々気づいたこと。1日1ファイルでも1週1ファイルでもいい |
| `03_定番コンテンツ/` | 何度も使える完成原稿。★資産の本体 |
| `04_たとえ話・フレーズ集.md` | 「伝わった言い方」のストック。24年分の財産 |
| `05_栄養の知識ベース/` | テーマ別の知識整理。発信の裏付けになる |
| `06_既存資料の索引.md` | 既に作ったスライド・PDFがどこにあるかのメモ |

## 入れないもの

- 実際に投稿した原稿 → `05_発信/`
- お客様の声そのもの → `03_顧客/`（ここには「素材として抜き出したもの」を置く）
- 外から学んだこと → `08_学び・リサーチ/`（自分の言葉になったら04へ移す）

## 素材が入ってくる道

```
03_顧客/よくある悩み・質問.md   ← お客様の生の言葉
00_司令塔/_INBOX.md            ← 日々の気づき
08_学び・リサーチ/学びログ/     ← 学んで自分の言葉になったもの
        ↓  週1回の棚入れで
   ここ（04_コンテンツ資産）
        ↓
     05_発信 へ
```

## 命名例

- `02_気づき・体験ログ/2026-09-14_気づき_朝食を抜く人の本当の理由.md`
- `03_定番コンテンツ/たんぱく質は朝が勝負.md`
- `05_栄養の知識ベース/腸と便通.md`
