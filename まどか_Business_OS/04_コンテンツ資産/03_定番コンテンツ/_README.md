# 03_定番コンテンツ ★資産の本体

## 入れるもの

**何度も使い回せる完成原稿。**
一度書いたら、媒体を変えて繰り返し出せるものだけを置きます。

## ここに入れる基準（どれか1つ当てはまれば）

- 3回以上聞かれた質問への答え（`03_顧客/よくある悩み・質問.md` を見る）
- 発信して反応が良かったもの（`07_数字/発信反応ログ.md` を見る）
- セミナーで毎回話している内容
- 商品の中で必ず伝えていること

## 大事な考え方

発信は毎回新しく作るものではありません。
**同じことを、言い方を変えて繰り返す**のが届く方法です。
だからここに10本あれば、1年分の発信がまわります。

## ファイルの中に書くこと

```
# タイトル

タグ5行

## 結論（一言）
## なぜそう言えるか
## 具体的にどうするか
## よくある勘違い
## 使ったところ（日付・媒体・反応）
```

最後の「使ったところ」を書き足していくと、どれが効いているか分かります。

## 命名例

- `たんぱく質は朝が勝負.md`（日付なし・更新型）
