# セミナー・講座

## 入れるもの

実施したセミナー・講座の記録。1回1ファイル。

## 命名例

- `2026-08-20_セミナー_夏休みの終わり第2回.md`

## ファイルに書くこと

```
タグ5行

## 基本情報
- 日時／対象／人数／依頼元／スライド資料の場所

## 話した内容（章立て）

## 参加者の反応・質問  ← ★ここが一番価値がある
（→ 03_顧客/よくある悩み・質問.md に転記）

## うまくいったこと

## 次回直すこと

## 使ったスライド
（→ 04_コンテンツ資産/06_既存資料の索引.md に所在を記録）
```

## ★ 参加者の質問を必ず残す

セミナーの質問は「その場にいる人が本当に知りたいこと」です。
発信ネタとして最も確実な素材になります。
終わったらすぐ書き留めて、`03_顧客/よくある悩み・質問.md` に転記してください。

## スライド本体の置き場所

スライド（pptx）はファイルサイズが大きいので、ここに入れず
`04_コンテンツ資産/06_既存資料の索引.md` に**所在を書く**方式にしています。
