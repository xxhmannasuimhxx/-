# 05_発信

## このフォルダの役割

**実際に世に出したもの**を置く場所。過去の発信を探せる状態にしておくためです。

## 入れるもの

- 発信の予定と実績（`発信カレンダー.md`）
- 媒体ごとの原稿（下書き／投稿済み）

## 入れないもの

- 発信のネタ・素材 → `04_コンテンツ資産/`
- 反応の数字 → `07_数字/発信反応ログ.md`
- セールス用の文面 → `06_セールス/セールス文面集/`

## 使い方の流れ

```
04_コンテンツ資産/01_ネタ帳.md からネタを選ぶ
   ↓
05_発信/（媒体）/下書き/ で書く
   ↓
出したら 投稿済み/ へ移動
   ↓
07_数字/発信反応ログ.md に反応を記録
   ↓
反応が良かったら 04_コンテンツ資産/03_定番コンテンツ/ へ
```

★ この最後のステップ（定番化）が資産を作ります。
出して終わりにせず、良かったものは必ず定番に昇格させてください。

## 命名例

- `Instagram/投稿済み/2026-09-14_投稿_朝食を抜く人の本当の理由.md`
- `メルマガ/配信済み/2026-09-10_メルマガ_たんぱく質は朝が勝負.md`
- `セミナー・講座/2026-08-20_セミナー_夏休みの終わり第2回.md`
