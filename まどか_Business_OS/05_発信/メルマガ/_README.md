# メルマガ

## フォルダの使い分け

- `下書き/` … 書いている途中のもの
- `配信済み/` … 実際に出したもの（出したら移動する）

## 命名例

`配信済み/2026-09-14_メルマガ_内容を一言で.md`

## ファイルに書くこと

```
タグ5行（対象・悩み・商品・媒体・状態）

## 本文

## 出したあとのメモ
- 出した日時：
- 反応：（詳しくは 07_数字/発信反応ログ.md）
- 次に活かすこと：
```

## ★ 出したあとにやること

1. `07_数字/発信反応ログ.md` に反応を記録
2. 反応が良ければ `04_コンテンツ資産/03_定番コンテンツ/` に昇格
3. `04_コンテンツ資産/01_ネタ帳.md` の状態を「発信済み」に更新
