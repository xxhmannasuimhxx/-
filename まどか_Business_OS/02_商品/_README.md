# 02_商品

## このフォルダの役割

「何を売るか」を管理する場所。1商品1フォルダで、設計・提供内容・改善メモをまとめます。

## 入れるもの

- 商品の一覧と状況（`商品一覧.md`）
- まだ形になっていない構想（`商品アイデア.md`）
- 商品ごとのフォルダ（設計書・提供内容・改善メモ）

## 入れないもの

- 売るための文面・LP → `06_セールス/セールス文面集/`
- お客様の成果 → `03_顧客/`
- 講座で話す中身の素材 → `04_コンテンツ資産/`
- 終わった商品 → `09_アーカイブ/終了した商品/`

## 商品フォルダの作り方

新しい商品を作るときは、フォルダを1つ作って `_テンプレート/商品設計書.md` をコピーする。

```
02_商品/
└─ 朝食リセット講座/
    ├─ 商品設計書.md      ← テンプレをコピー
    ├─ 提供内容.md        ← 実際に渡すもの・当日の流れ
    └─ 改善メモ.md        ← 提供して気づいたこと
```

作ったら `商品一覧.md` に1行追記する。

## 命名例

- `02_商品/朝食リセット講座/商品設計書.md`
