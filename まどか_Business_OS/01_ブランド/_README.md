# 01_ブランド

## このフォルダの役割

**判断の軸**を置く場所。
「この発信をするか」「この仕事を受けるか」「この言い方でいいか」を迷ったとき、
ここに書いてあることと照らして決めます。

## 入れるもの

- 誰に・何を・なぜ私が（`ブランドコア.md`）
- 24年間の経験の棚卸し（`専門性の棚卸し.md`）
- 原体験・ストーリー（`私の物語.md`）
- 理想のお客様像（`理想のお客様.md`）
- 使う言葉／使わない言葉（`言葉の定義集.md`）

## 入れないもの

- 個別の発信内容 → `05_発信/`
- 商品の中身 → `02_商品/`
- 日々の気づき → `04_コンテンツ資産/02_気づき・体験ログ/`

**このフォルダは頻繁に書き換えません。** 四半期に1回見直す程度でいい。
ブラさないことに意味があります。

## 命名例

日付なし・更新型のファイルだけ置きます（`ブランドコア.md` など）。
