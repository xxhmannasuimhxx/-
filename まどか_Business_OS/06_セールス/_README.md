# 06_セールス

## このフォルダの役割

「知ってもらう」から「買っていただく」までの**流れと文面**を管理する場所。

## 入れるもの

- 全体の流れ（`セールス導線.md`）
- 価格とオファーの設計（`価格・オファー設計.md`）
- 使い回せる文面（`セールス文面集/`）
- 販売した回ごとの記録（`ローンチ記録/`）

## 入れないもの

- 商品の中身 → `02_商品/`
- 通常の発信 → `05_発信/`
- 売上の数字 → `07_数字/`

## ★ セールス文面は「作る」より「集める」

売れる文面の材料は、ほぼ全部 `03_顧客/` にあります。

| 文面のパーツ | どこから持ってくるか |
|---|---|
| 悩みの描写 | `03_顧客/よくある悩み・質問.md`（お客様の言葉そのまま） |
| 不安への答え | `03_顧客/お客様の声/` のQ3 |
| 買う理由 | `03_顧客/お客様の声/` のQ2 |
| 変化の証明 | `03_顧客/ビフォーアフター記録/` |
| 信頼の根拠 | `01_ブランド/専門性の棚卸し.md` |

ゼロから書こうとしないでください。**引っぱってくるだけで書けます。**

## 命名例

- `ローンチ記録/2026-10_ローンチ_朝食リセット講座_第1期.md`
- `セールス文面集/LP_朝食リセット講座.md`
