# ローンチ記録

## 入れるもの

販売した回ごとの記録。1回1ファイル。
テンプレート：`../_テンプレート/ローンチ振り返り.md`

## 命名例

- `2026-10_ローンチ_朝食リセット講座_第1期.md`

## ★ 必ず書いてほしいこと

**「買わなかった人の理由」** と **「一番効いたこと」** の2つです。

この2つが回を重ねて溜まると、
新しいことをやらなくても売れるようになります。
逆にこれがないと、毎回ゼロからやり直しになります。

## 回をまたいだ比較

回が3つ以上溜まったら、このフォルダに `比較表.md` を作って
各回の人数・率・売上を並べてください。傾向が見えます。
