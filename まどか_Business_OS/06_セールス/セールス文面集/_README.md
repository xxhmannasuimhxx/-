# セールス文面集

## 入れるもの

**使い回せる文面の型。** 一度書いたら次回は直すだけで済むようにします。

## 置くファイルの例

- `LP_商品名.md` … 販売ページの本文
- `セールスメール_商品名.md` … 販売期間中のメール（複数通）
- `個別相談の流れ.md` … 相談で何をどの順で聞くか
- `DM返信の型.md` … よく来る問い合わせへの返し方
- `お申込み後の案内.md` … 申込直後に送る文面
- `お断りの文面.md` … 対象外の方へのお断り

## ★ 書き方

ゼロから書かないでください。`_README.md`（06直下）の表のとおり、
材料は `03_顧客/` にあります。

**LPの基本の並び**（迷ったらこの順）

```
1. こんなことで困っていませんか   ← 03_顧客/よくある悩み・質問.md の言葉そのまま
2. それはあなたのせいではない
3. 実はこういうことです（原因）   ← 04_コンテンツ資産/05_栄養の知識ベース/
4. だからこうすればいい（解決）
5. その方法がこれです（商品）     ← 02_商品/商品設計書.md
6. 実際に変わった人がいます       ← 03_顧客/お客様の声/
7. なぜ私が言えるのか             ← 01_ブランド/専門性の棚卸し.md
8. よくある不安への答え           ← 03_顧客/お客様の声/ のQ3
9. 価格と申込方法                 ← 06_セールス/価格・オファー設計.md
```

## ★ 表現に気をつける

`01_ブランド/言葉の定義集.md` の「気をつける表現」を必ず確認してください。
効果を断定する表現、医薬品的な効能の表現は使いません。
