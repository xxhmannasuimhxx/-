# 07_数字

## このフォルダの役割

**「何が刺さったか」を知るため**の場所。経営の成績表ではありません。

## ★ 大事な前提：数字は少なく

追う指標は**3〜5個まで**。増やすと記録が続かなくなり、結局何も見なくなります。
`指標の定義.md` で「見ない数字」まで決めてあるのはそのためです。

## 入れるもの

- 何を見るか／見ないか（`指標の定義.md`）
- 月ごとの推移（`月次サマリー.md`）
- 月ごとの詳細（`月別データ/2026-09.md`）
- 投稿単位の反応（`発信反応ログ.md`）

## 入れないもの

- 個別の売上明細・決済情報（会計ソフトで管理する）
- 発信の原稿 → `05_発信/`

## 月1回20分の手順

1. `月別データ/YYYY-MM.md` を作って数字を書く
2. `月次サマリー.md` の表に1行追記
3. **反応が良かった発信を3つ選ぶ**
4. その3つの共通点を1行書く ← ★ここが本番
5. 良かったものを `04_コンテンツ資産/03_定番コンテンツ/` に昇格

1〜2は作業、**3〜5が価値**です。時間がないときは3〜5だけやってください。

## 命名例

- `月別データ/2026-09.md`
