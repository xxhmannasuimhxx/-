# 指標の定義

> 何を見るか、そして**何を見ないか**を決めておく。
> 決めておかないと、数字に振り回されて発信が怖くなります。

---

## 見る数字（3〜5個まで）

| 指標 | なぜ見るか | どこで確認するか | 今の目安 |
|---|---|---|---|
|  |  |  |  |

<!-- 記入例：
| メルマガ／LINE登録者数 | 継続的に届けられる人の数。ここが土台 | 配信ツール管理画面 | 月+20人 |
| 保存数（Instagram） | 「あとで読みたい」= 役に立った証拠 | インサイト | 投稿あたり30 |
| 個別相談の申込数 | 売上に直結する段階 | 予約フォーム | 月5件 |
| 売上 | - | 会計ソフト | 月◯円 |
-->

## ★ 見ない数字（理由も書く）

| 見ない数字 | 理由 |
|---|---|
|  |  |

<!-- 記入例：
| フォロワー数 | 増えても売上に直結しない。気にすると発信内容がぶれる |
| いいね数 | その場の反応でしかない。保存数の方が役に立った証拠になる |
| 他の人の数字 | 前提が違うので比較しても判断材料にならない |
-->

**フォロワー数を追わないと決める**だけで、発信の質が変わります。
見る数字は「お客様の役に立ったか」を測れるものを選んでください。

## 目標の立て方

<!-- 記入例：
売上目標だけを立てない。
「売上◯円」＝「講座◯人」＝「個別相談◯件」＝「セミナー◯人」＝「登録◯人」
まで分解して、一番手前の数字（登録数）を見る。
手前の数字は自分の行動で動かせるが、売上は直接動かせない。 -->


## 記録するタイミング

| 何を | いつ | どこに |
|---|---|---|
| 投稿の反応 | 投稿の3日後 | `発信反応ログ.md` |
| 月の数字 | 月初 | `月別データ/YYYY-MM.md` |
| 推移 | 月初 | `月次サマリー.md` |

## 数字を見るときの約束

- 下がった月があっても、原因を1つ探して終わりにする（自分を責めない）
- 3ヶ月の流れで見る（1ヶ月の上下は判断材料にならない）
- 数字が悪いときは `03_顧客/よくある悩み・質問.md` に戻る（お客様を見る）
