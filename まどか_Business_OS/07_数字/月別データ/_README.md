# 月別データ

## 入れるもの

1ヶ月1ファイル（`2026-09.md`）。その月の数字と、気づいたこと。

## ファイルに書くこと（この形をコピーして使う）

```markdown
# 2026-09

## 数字
| 指標 | 今月 | 先月 | 差 |
|---|---|---|---|
| 登録者数 |  |  |  |
| 発信本数 |  |  |  |
| 相談件数 |  |  |  |
| 購入数 |  |  |  |
| 売上 |  |  |  |

## 今月やったこと（3つ）
1.
2.
3.

## 反応が良かった発信（3つ）
1.
2.
3.

## その3つの共通点   ← ★ここが一番大事
（例：どれも「がんばらなくていい」という切り口だった）

## 反応が薄かったもの

## 来月やること（1つだけ）
```

## ★ 時間がないときは

「反応が良かった発信3つ」と「その共通点」だけ書いてください。
数字の記入は飛ばしていいです。共通点の蓄積が、発信の精度を上げます。
