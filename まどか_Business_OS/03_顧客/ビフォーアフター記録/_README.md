# ビフォーアフター記録

## 入れるもの

お客様の**変化**の記録。1人1ファイル（`C0XX_変化記録.md`）。

| 項目 | 開始時 | 1ヶ月 | 3ヶ月 | メモ |
|---|---|---|---|---|
| 体重 |  |  |  |  |
| 排便の回数 |  |  |  |  |
| 朝の状態 |  |  |  |  |
| 本人の言葉 |  |  |  |  |

**数値だけでなく「本人の言葉」を必ず残す。** 数値は説得力に、言葉は共感に使えます。

## ★ 注意

- 本人が特定できる形の医療情報は書かない
- 発信で使うときは必ず許可を取り、`許可: 済（日付）` を記録する
- 写真を置く場合は、顔や特定できるものが写っていないか確認する

## 入れないもの

- 感想文 → `お客様の声/`
