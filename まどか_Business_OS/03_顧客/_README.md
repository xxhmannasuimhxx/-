# 03_顧客

## ★ このフォルダだけの最重要ルール：個人情報を書かない

このOSはGitで管理されているため、**一度書いたものは履歴に残り、削除しても履歴からは消えません。**

### 書かないもの

- 本名・メールアドレス・電話番号・住所・SNSアカウント名
- 本人が特定できる形の健診結果・病歴
- 決済情報

### 書き方

- お客様は **`C001` のようなID** で管理する（必要ならイニシャルまで）
- **本名とIDの対応表は、このOSの外に置く**（顧客管理ツール、または手元の非公開ファイル）
- お客様の声は**掲載許可を得たものだけ**を入れ、ファイル内に `許可: 済（YYYY-MM-DD）` を書く
- 許可がまだのものは `許可: 未` と書き、発信には使わない

---

## このフォルダの役割

**素材の源泉。** ここが埋まっていると、発信もセールスも商品改善も全部楽になります。
「お客様が実際に使った言葉」が一番価値があります。要約せず、そのまま書き留めてください。

## 入れるもの

- お客様ごとの記録（`お客様カルテ` → 各自のファイル）
- いただいた声（`お客様の声/`）
- 数値・状態の変化（`ビフォーアフター記録/`）
- 相談内容の集計（`よくある悩み・質問.md`）← **ここから発信ネタが生まれます**

## 入れないもの

- 発信の原稿 → `05_発信/`
- 商品の設計 → `02_商品/`
- 本名などの個人情報 → このOSの外

## 命名例

- `お客様の声/2026-09-01_お客様の声_C003_朝が楽になった.md`
- `ビフォーアフター記録/C003_変化記録.md`
- `カルテ/2026-04-01_カルテ_C003.md`（カルテを作る場合は `カルテ/` を新設）
