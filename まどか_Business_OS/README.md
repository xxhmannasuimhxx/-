# まどか Business OS

管理栄養士としての24年間の経験・発信・お客様の変化・商品・学びを一元管理し、
**過去の資産を検索して再利用できる状態**にしておくための場所です。

## まず開く場所

| やりたいこと | 開くファイル |
|---|---|
| 何か思いついた・気づいた | `00_司令塔/_INBOX.md` |
| 今月何をやるか確認したい | `00_司令塔/ダッシュボード.md` |
| 書き方・命名のルールを確認したい | `00_司令塔/運用ルール.md` |
| 発信のネタを探したい | `04_コンテンツ資産/01_ネタ帳.md` |
| お客様の悩みを確認したい | `03_顧客/よくある悩み・質問.md` |

## 全体の地図

```
00_司令塔        いま何をやるか（入口・司令塔）
01_ブランド      誰に・何を・なぜ私が（判断の軸）
02_商品          何を売るか
03_顧客          誰が・何に困り・どう変わったか  ← 素材の源泉
04_コンテンツ資産 発信の材料庫                    ← このOSの心臓部
05_発信          実際に出したもの
06_セールス      売れる流れと文面
07_数字          何が刺さったか
08_学び・リサーチ 外から入れた知識
09_アーカイブ    終わったもの（捨てずに残す）
```

## このOSが回る仕組み

```
03_顧客（お客様の声・悩み）
   ↓ 素材として抜き出す
04_コンテンツ資産（ネタ帳・たとえ話・知識ベース）
   ↓ 組み立てて出す
05_発信（Instagram・メルマガ・セミナー）
   ↓ 反応を記録する
07_数字（どれが刺さったか）
   ↓ 刺さったものを土台に
06_セールス（導線・文面）
   ↓ 新しいお客様の声が生まれる
03_顧客 へ戻る
```

10個のフォルダは並列ではなく、この輪の一部です。
**04と03に素材が溜まるほど、発信もセールスも楽になります。**

## 続けるための唯一のルール

迷ったら分類しないで `00_司令塔/_INBOX.md` に1行書く。
分類は**週1回15分**まとめてやる。

詳しくは `00_司令塔/運用ルール.md` を見てください。
