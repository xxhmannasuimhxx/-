# 名刺（縦型 55 × 91 mm） ／ 髙落 まどか（管理栄養士）

リーフレット「食で、人生を整える」の構成・配色・書体をそのまま名刺に落とし込んだものです。
裏面違いで2種類あります。**表面は共通**です。

| 種類 | ファイル | 裏面 |
| --- | --- | --- |
| **A：お仕事のご依頼**（リーフレット準拠） | `card.html` → `meishi_print.pdf` | 依頼4カテゴリ／「こんなこと、お願いできる？」／顔写真＋実績／連絡先＋QR |
| **B：おうちごはん処方箋** | `card_rx.html` → `meishi_rx_print.pdf` | その場で書き込める処方箋。名刺交換が小さな相談になる |

- 表面：「食で、人生を整える」＋氏名＋リード文＋3つの講座アイコン（健康・栄養講座／食育イベント／親子講座）
- プレビュー：`preview.png`（A）／`preview_rx.png`（B）／片面ずつは `preview_front.png` など
- 色・サイズはすべて `card.css` にまとめています

## 顔写真の入れ方（**未設定**）

裏面Aの写真枠は、いまは「写真」と書いた丸いプレースホルダーです。

1. 使いたい写真を **`meishi/photo.jpg`** という名前でこのフォルダに置く
2. `sh meishi/build.sh` を実行

これだけで丸くトリミングされて入ります。トリミング位置は `card.css` の
`.photo img { object-position: 50% 18%; }` で調整してください（数字を小さくすると上寄り＝顔が大きく入ります）。

## QRコード

`https://linktr.ee/shiawase.gohan` のQRを `qr.png` として生成済みで、裏面に配置してあります
（誤り訂正レベルQ・13mm角。360dpiの印刷サイズで読み取りテスト済み）。
URLを変える場合は `python3 meishi/make_qr.py <新しいURL>` で作り直してください。

## 入稿仕様

- 仕上がり **55 × 91 mm（縦型）** ／ 塗り足し **3mm**（PDFは 61 × 97 mm・2ページ）
- 1ページ目＝表面、2ページ目＝裏面。トンボなし（ラクスル・プリントパック等の「塗り足し3mm」テンプレートにそのまま使えます）
- 文字は仕上がり線から 4mm 内側に収めています
- 用紙：**マットコート／上質紙**がおすすめ。B案は裏面にペンで書き込むため光沢紙は不可
- 書体：Zen Old Mincho・Noto Serif JP・Noto Sans JP（Google Fonts）。
  未インストールの環境では游明朝／ヒラギノ明朝にフォールバックします
- お名前の「**髙**」（はしごだか）は環境依存文字です。PDFにはフォントが埋め込まれているので
  そのまま入稿できますが、印刷所で組み直す場合は字形が変わっていないか必ず確認してください

## 作り直し方

```sh
sh meishi/build.sh                    # PDF とプレビュー画像をまとめて再生成
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" sh meishi/build.sh   # Mac の場合
```

Chrome で `card.html` を開いて「印刷 → PDFに保存 → 用紙サイズ:カスタム(61×97mm)・余白なし・背景のグラフィック ON」でも同じものが作れます。

> `card_rx.html` の表面は `card.html` からのコピーです。表面を直すときは両方のファイルを更新してください。
