# 名刺 ／ 髙落 まどか（案A：ミニ処方箋）

講座スライド（`build_deck.js`）と同じブランドカラーで作った名刺です。

| ファイル | 内容 |
| --- | --- |
| `card.html` | デザイン本体（表・裏の2ページ）。ブラウザで開けばそのまま確認できます |
| `meishi_print.pdf` | 入稿用PDF（97 × 61 mm ＝ 仕上がり91×55 ＋ 塗り足し3mm、2ページ） |
| `preview_front.png` / `preview_back.png` | 仕上がりサイズに断裁した状態のプレビュー（360dpi） |
| `preview.png` | 表裏を並べたプレビュー |

## デザインの考え方

- **表面**：講座スライドの表紙と同じネイビー（`#13273F`）＋琥珀（`#D9822B`）。名前を主役にして、肩書き・キャッチコピー・講座名だけに絞る。
- **裏面**：「おうちごはん処方箋」。渡した相手がその場で気になることにチェックを入れられ、`Rp.` の欄に一言書いて渡せる。**名刺交換が小さな相談体験になる**のがこの案の狙いで、書き込んだ名刺は捨てられずに残ります。
- 裏面のうっすらした方眼は処方箋・カルテの雰囲気づけ。書き込みの邪魔にならない濃さにしています。

## 差し替えが必要なところ（現在は仮置き）

`card.html` の裏面パートを書き換えてください。

- `.contact` … `example@example.com` / `@example` / `example.com` を実際のメール・Instagram・LINE・サイトに
- `.qr` … `<div class="qr">QR</div>` を `<img class="qr" src="qr.png">` に差し替え（15×15mm、余白なしの画像を推奨）
- `.qr-cap` … QR下の説明文
- `.checks` … チェック項目（現在：朝ごはん／好き嫌い／おやつ／夜ふかし／お弁当／その他）
- `.copy`・`.sub` … キャッチコピーと説明文

## 入稿仕様

- 仕上がり **91 × 55 mm**（日本の標準名刺サイズ）／ 塗り足し **3mm**（PDFは97 × 61mm）
- トンボなし。ラクスル・プリントパックなど「塗り足し3mm・トンボ不要」のテンプレートにそのまま使えます
- 文字は仕上がり線から4mm内側に収めています
- 用紙は上質紙・マットコート系がおすすめ（裏面に**ペンで書き込む**ため、光沢紙は不可）

## PDFの作り直し方

`card.html` を編集したあと、Chrome / Edge で開いて「印刷 → PDFに保存 → 余白なし・背景のグラフィック ON」でも作れます。
コマンドで作る場合：

```sh
chrome --headless --no-pdf-header-footer \
  --print-to-pdf=meishi_print.pdf meishi/card.html
```
