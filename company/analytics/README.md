# 集客・売上分析（第2段階）

計画書 → `../01_management/2026-10-22_集客売上分析システム_開発計画.md`

**個人情報（名前・メール・電話・相談内容）は、このフォルダのどこにも置かない。**
架空データはファイル名を `sample_` で始め、中身にも【架空】と付け、本番の数字と混ぜない。

## 使い方（AIスタッフ向け。代表はチャットでスクショを貼るだけ）

```bash
cd company/analytics
node sample/generate.mjs          # 架空データを作る（毎回同じ内容）
node src/build.mjs --sample       # 架空データで .xlsx とレポート下書きを作る → out/
node --test tests/*.test.mjs      # テスト（21件）

# ↓ 本番（実データへの切替は代表の承認後）
node src/import.mjs <CSV>         # 取り込み。見出しでツールを判定し、許可リストの列だけ data/ に追記
node src/build.mjs                # data/ と _shared/metrics.csv から作る → out/ と reports/
```

- スクショの数字は、AIが正規化した見出し（`config/sources.json` の列名）でCSVに書き起こしてから `import.mjs` に渡す
- ツールから書き出した**生のCSVは `inbox/` に置く**（`.gitignore` 済み＝リポジトリに入らない）
- 依存ライブラリなし（Node 標準のみ）。.xlsx も自前で書き出す

## フォルダ

| 場所 | 中身 |
|---|---|
| `docs/取込マッピング.md` | 各ツールの画面のどの数字を、どの列名で取り込むか |
| `config/sources.json` | 取り込んでよい列の許可リスト（ここに無い列は捨てる） |
| `src/` | `lib`（CSV・週・数字）／`calc`（計算）／`import`（取込）／`xlsx`（書き出し）／`build`（集計・レポート） |
| `sample/` | 架空データの生成と、その出力 |
| `tests/` | 自動テスト |
| `data/` | 本番の正規化データ（集計値のみ。10/24 から実データ） |
| `out/` | スプレッドシート用 .xlsx（Googleドライブにアップロードして見る） |
| `reports/` | 週次分析レポート |

## 計算の決まりごと

- 週＝**土曜〜金曜**、金曜の日付で表す（`_shared/metrics.csv` と同じ）
- 記録の無い週・項目は**空欄**。0で埋めない
- 分母が30未満の率は「**参考値（n=○）**」と表示
- メルマガの主指標は**実質開封率**（クリック率は計測されていない）
- 施策の判定：期間中の平均と、直前の同じ週数の平均を比べる。±10%以上で改善／悪化、どちらかが2週未満なら**判定不能**
- 計算式の一覧は .xlsx の「定義」タブ
