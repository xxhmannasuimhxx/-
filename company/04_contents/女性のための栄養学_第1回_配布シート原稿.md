## 代表へ：この文書の使い方

**紙に印刷される文字が、そのまま書いてあります。** デザインに流し込めば完成する状態です。

| 記号 | 意味 |
|---|---|
| `▢` | 記入欄（枠線） |
| `［　］` | 短い記入欄 |
| 【数字は代表が確定】 | ここだけ、代表が言い切れる数字を入れてください |
| ★ | 代表の言葉に置き換え推奨 |

### 全5枚の共通仕様

- **A4・縦**（③のみ横）。1枚1テーマ。**両面印刷しない**（書きながらめくる動作をなくす）
- **余白は広く。** 文字で埋めない。書く場所のほうが広い紙にする
- フッター共通：`女性のための栄養学 第1回 ／ スマイルおうち栄養士` ＋ ページ番号
- オンライン配布用に**PDF1本にまとめたもの**と、**1枚ずつ**の両方を用意（プリンタがない方が多い）
- ◆ **どのシートにも「判定」「点数」「合計」を入れない。** 医療的判断に見せない

### 5枚の役割

| # | シート名 | 使う場面 | 持ち帰りに効くか |

| ① | からだのリズム地図 | 章0・全体の背骨 | 第2回でも使う |

**印刷する文字**

- タイトル：`からだのリズム地図`
- サブ：`初経から、閉経まで。ひとつながりで見てみます。`
- 4区分の見出し：`成長期` / `安定期` / `ゆらぎ期` / `その先`【年代の区切りは代表が確定】
- 行見出し：`からだに起きること` / `よくあるゆれ` / `この時期の土台`
- 書き込み指示：`いま自分がいるあたりに、↑ を書き入れてください。`
- 脚注：★ `この地図は、次回も使います。捨てないでください。`

> 💡 **各マスの中身は、代表が話す内容で埋まります。** わたしが文章を入れると、講座が"読む時間"になります。
> **空欄のまま印刷し、話しながら受講生が埋める**形を推奨します（手が動くほど持ち帰ります）。

# ③ 記録シート（3項目・2週間）

**A4・横／★この回の持ち帰り1。宿題そのもの**

```
┌──────────────────────────────────────────────┐
│ わたしの記録　　　1日3分。書けない日は、空けたままで大丈夫です。   │
│                                                              │
│  記録する3つを、自分で決めます → ①［        ］              │
│  （例：痛み／気分／眠り／体温／食欲）  ②［        ］          │
│                                        ③［        ］          │
│                                                              │
│  日  │ 月/日 │  ①  │  ②  │  ③  │ ひとこと（任意）        │
│ ────┼──────┼─────┼─────┼─────┼──────────────│
│  1   │  /   │ ▢   │ ▢   │ ▢   │                        │
│  2   │  /   │ ▢   │ ▢   │ ▢   │                        │
│ （14日分・同じ行が続く）                                      │
│  14  │  /   │ ▢   │ ▢   │ ▢   │                        │
│                                                              │
│  書き方は自由です。○△× でも、数字でも、ひとことでも。       │
│                                                              │
│  ◆ 空いている日があっても、それも記録です。                  │
│  ★ 次回、この紙を開きながら進めます。持ってきてください。     │
└──────────────────────────────────────────────┘
```

**印刷する文字**

- タイトル：`わたしの記録`
- サブ：`1日3分。書けない日は、空けたままで大丈夫です。`
- 記入指示：`記録する3つを、自分で決めます`
- 例示：`（例：痛み／気分／眠り／体温／食欲）` ← **例は5つまで。増やすと選べなくなります**
- 凡例：`○△× でも、数字でも、ひとことでも。書き方は自由です。`
- 脚注：◆ `空いている日があっても、それも記録です。`

> 💡 **3項目を代表が指定しないでください。** 自分で決めた項目だから続きます。
> 💡 スマホで書く方のために、**同じ3項目のメモ帳テンプレ（コピペ用テキスト）**も一緒に配ると継続率が上がります。

**スマホ用テンプレ（そのまま送付）**
```
【わたしの記録】
◯月◯日
①（　　　）
②（　　　）
③（　　　）
ひとこと：
```
