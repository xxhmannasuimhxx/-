## ⚠ こちらの見落とし：mailmag が、すでにありました

11/1に、別セッションで **`mailmag/`（メルマガ自動投稿のしくみ）** が作られていました。
**その21時間後に、こちらはメルマガ5通の骨組みを納品しています。**

**つながることに気づいていませんでした。** いま接続します。

### 2つを合わせると、こうなります

```
① 代表が書く（聖域）
      ↓
② mailmag/drafts/ に .md として置く
      ↓
③ GitHub Actions が動く
      ↓
④ リザストに「下書き」として入る
      ↓
⑤ 代表が中身を見て、配信ボタンを押す
```

**②は、代表がやらなくて構いません。**
`CLAUDE.md` にこう書いてあります。

> 「メルマガの下書きに入れて」と頼まれたら、**代表が書いた本文をそのまま**（文章は直さない）
> `mailmag/drafts/YYYY-MM-DD-なまえ.md` に保存し、main にコミット＆プッシュする。

### つまり、メルマガ5通の手順はこうなります

| 誰が | 何を |
|---|---|
| マキ | **骨組みと素材を渡す**（✅ 11/02 納品済み） |
| **代表** | **それを見て、本文を書く**（聖域。チャットに貼るだけ） |
| ハル | **「下書きに入れて」の一言で、ファイル化・プッシュ** |
| GitHub Actions | リザストに下書きとして保存 |
| **代表** | 中身を見て、**配信ボタンを押す** |

**代表の作業は「書く」と「押す」だけ**になりました。
ファイル操作も、リザストへの貼り付けも、要りません。

> **これは大きいです。** 5通ぶんの事務作業が消えました。
