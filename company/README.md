## フォルダの役割

| フォルダ | 役割 | 主な中身 |
|---|---|---|
| `00_inbox/` | 代表のブレインダンプ置き場（全ての入口） | 思いつきメモ |
| `01_management/` | 経営・戦略・コンセプト設計 | 戦略メモ、意思決定ログ |
| `02_marketing/` | 集客・SNS・導線設計 | リール企画、キャプション、導線設計 |
| `03_sales/` | 販売・LP・セールスライティング | LP原稿、セールスメール、FAQ |
| `04_contents/` | コンテンツ・カリキュラム・記事 | カリキュラム、原稿、スライド構成 |
| `05_operations/` | 事務・スケジュール・タスク管理 | board.md、チェックリスト、ログ |
| `_shared/` | 全社共有資産 | ブランド、ペルソナ、商品、KPI |
| `_templates/` | 成果物テンプレート | 各種ひな形 |

## はじめかた

**→ `HOW_TO_RUN.md`（動かし方）を読んでください。** 週30分でまわす設計です。

最短ルートは3ステップ。

1. `/onboard` … 5人がインタビューして理念・商品・ペルソナを埋める（15分・答えるだけ）
2. `/kickoff` … 今週やること3つを決める（5分）
3. `/braindump` … 思いついたことを整理せずに投げる（随時）
