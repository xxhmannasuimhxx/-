## 主商品

### 連続講座「スマイルおうち栄養士講座」／ 通常148,000円・プレミアム198,000円（税込）
**これが売上の柱。会社のすべての導線はここに向かう。**

#### 講座の形（2026-09-28 確定）

| 要素 | 内容 |
|---|---|
| 全体 | **全6テーマ／期間 半年** |
| ① 動画講座 | **21本**（1本 40〜90分）・オンデマンド |
| ② グループ実践会 | 30分 |
| ③ グループシェア会 | 90分 |
| ライブ回数 | 各テーマ2回 × 6 ＝ **全12回**（約2週に1回） |
| アーカイブ | **1年間** 視聴可 |
| 質問・相談 | **LINEでいつでも** |
| 定員 | **10名**（少人数制） |
| 受講料 | **通常 148,000円 ／ プレミアム 198,000円** |
| プレミアム差分 | 月1回45分の個別1on1 × 6回（＝50,000円／1回あたり約8,300円） |
| お支払い | クレジットカード（Stripe）・銀行振込 |
| 目標 | **最低5名 / 満席10名** |
| 次期開講 | **2026年12月 予定** |
| 受講生の声 | **6件 確保済み**（LP掲載済み） |

> **セールス上の最大の武器は「動画が主軸」であること。**
> 迷う理由の1位が「時間が取れるか」なので、
> **「決まった時間に予定を空ける必要がない」**と言い切れるのは非常に強い。
> ただし「21本」を量として見せると逆効果。**「1ヶ月3〜4本」「1本40分から」**と分母を小さく示す。

- 受講動機は「資格・仕事にするため」ではなく、**まず自分と家族のため**
- したがって**養成講座としてではなく「体系的に学び直す場」として語る**
- 申込の決め手：自分の家を整えたい／家族の栄養バランスと自分自身の不調／まどかさんから学びたい
- 迷う理由：**時間が取れるか／自分にできるか**（※**価格は挙がっていない**。値引きで解決しようとしない）
